# OrienRun (intégré à Mes Apps EPS)
Dépôt conseillé : `OrienRun` → https://vinztoc.github.io/OrienRun/ (même origine que le portail : la base d'élèves est partagée).
- Sélection : classe puis élève(s) (équipe possible) lus dans la liste commune (IndexedDB « MesAppsEPS »).
- Résultat enregistré par élève : colonnes APP_orienrun_date / parcours / temps / balises / equipe / nb_seances (dernière séance).
- Firebase, Google Fonts et CDN supprimés : plus aucune donnée ne quitte l'appareil. Leaflet est embarqué dans vendor/.
- Seul le fond de carte OpenStreetMap nécessite une connexion.
